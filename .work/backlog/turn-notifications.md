# Turn notifications

Real "your turn" notifications instead of share-sheet nudges. A web app can't send push without something holding a private key. Options: ntfy app on both phones (least work; messages go via ntfy.sh, third party), a small free Cloudflare Worker sending web push (needs a Cloudflare account), Firebase Cloud Functions (Blaze plan, card). Try only if the share-sheet nudge on Send isn't enough.
