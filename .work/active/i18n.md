# Norwegian app text

## Goal
The app's own text (screens, buttons, messages, notifications, share text) in English and Norwegian (Bokmål). Each phone follows its language setting, with a switch to override it. Text sent to the other player (notification, share sheet) is in their language when the game knows it, otherwise the sender's.

## Acceptance
- [x] A phone set to Norwegian (nb, nn, no) shows every screen in Norwegian; any other language gets English
- [x] A switch on the games list (English / Norsk) overrides the phone and is remembered
- [x] Notification and share text go out in the partner's language when known, else the sender's
- [x] Every string has both languages (unit test), every key used in app.js and index.html exists
- [x] No side scroll with the longer Norwegian text on a 360 px phone
- [x] Existing unit and e2e suites still pass

## Decisions
- Strings live in `i18n.js` (pure, tested); `game.js` returns codes (`gameStatus().kind`), not text.
- The partner's language is stored per game at `players/<seat>/lang` (written on create, join and when opening the game): the rules already allow it, no rules change needed.
- Switching language reloads the page (static text is applied once at start).
- The word language of a new game defaults to the app language until the player picks one.

## Tests decided before implementation
- Unit `tests/i18n.test.mjs`: detectLang (override wins; nb-NO/nn/no → no; en-US/sv/empty → en); en and no have the same keys and placeholders; plurals (1 vs 2 guesses, "1 bokstav"/"8 bokstaver", "3 + 5 letters"); every `t("…")` key in app.js and every `data-i18n*` key in index.html exists.
- Unit `game.test.mjs`: gameStatus returns `kind` codes instead of text.
- E2E `tests/i18n.e2e.mjs` (local mode): nb-NO phone sees Norwegian setup, list and game; switch to English persists across reload; Norwegian player and English player: each one's share/notification text arrives in the receiver's language; no side scroll at 360 px.
- Existing suites: game, webpush, two-player, lobby, push, stale-deploy.
